## Миссия

**Сначала задача бизнеса. Затем — сервис, который её решает.**

RuCorp развивает практическую цифровую инфраструктуру для микро- и малых предприятий. Мы превращаем реальные потребности предпринимателей в сервисы с полезными функциями, простым подключением и минимальными наценками. Критерий успеха каждого проекта прост: стало ли бизнесу легче работать?

## Ориентир

[МСП.РФ](http://мсп.рф) — наш ориентир. Мы фокусируемся на практической стороне поддержки: создаём инфраструктуру и сервисы, которыми предприниматели могут пользоваться в ежедневной работе.

## Первый проект

### [Lovii](http://lovii.ru)

Первый проект RuCorp — SaaS-платформа и локальный маркетплейс для действующего бизнеса: общепита, услуг и сервисов. Добавить бизнес на витрину можно прямо со смартфона. См. [публичное описание платформы](https://github.com/lovii-ru/lovii-docs/blob/main/public/README.md).

Lovii объединяет маркетинг, работу с чеками и кассой.

- **Подключение:** бесплатно.
- **Модель оплаты:** с чека — без предварительных затрат на старт.
- **Совокупная нагрузка на торговую точку по заказу:** не более 10% от суммы заказа, включая эквайринг ([параметры тарифа](https://github.com/lovii-ru/lovii-docs/blob/main/canon/PARAMS.md#11-%D0%BD%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B0-%D0%BD%D0%B0-%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%B0-%D0%BC%D1%81%D0%BF)).

Подробности и подтверждающие материалы: [публичное описание и документы](https://github.com/lovii-ru/lovii-docs/tree/main/public), [схема движения средств](https://github.com/lovii-ru/lovii-docs/blob/main/public/money_flow_public.md), [канонические тарифы и параметры нагрузки](https://github.com/lovii-ru/lovii-docs/blob/main/canon/PARAMS.md) и [полный корпус документации](https://github.com/lovii-ru/lovii-docs). Сайт проекта — [lovii.ru](http://lovii.ru).

## Как мы работаем

`ПОТРЕБНОСТЬ` → `ИНФРАСТРУКТУРА` → `ЗАПУСК` → `УЛУЧШЕНИЕ`

| Этап | Фокус |
| --- | --- |
| **Потребность** | Находим практическую задачу микро- или малого предприятия. |
| **Инфраструктура** | Создаём сервис или инструмент, который помогает решить эту задачу. |
| **Запуск** | Делаем решение доступным с минимальными наценками и полезным набором функций. |
| **Улучшение** | Развиваем проект, сохраняя фокус на практической ценности для бизнеса. |

## Принципы

- **Практическая польза.** Каждый проект должен помогать в реальной работе предприятия.
- **Доступная экономика.** Стремимся к минимальным наценкам.
- **Функции по делу.** Приоритет — максимальная полезность, а не сложность ради сложности.
- **Ясная ответственность.** У каждого проекта и результата есть ответственные.
- **Временный мандат.** Команды и роли формируются под задачу; дальнейшая работа требует ясной цели.
